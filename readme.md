## Git frågor
### Vad är skillnaden mellan git add och git commit?

"Git add" lägger till filer eller ändringar i något som kallas staging area. Staging area innehåller de ändringar som man har bestämt ska med i nästa commit.
"Git commit" gör en ögonblickbild av de ändringar som finns i staging area och sparar den i git-historiken.

### Varför använder man branches istället för att jobba direkt i main?
Eftersom man kan arbeta på nya funktioner eller buggfixa utan att påverka själva huvudgrenen, vilket är main. Man kan säga det är en parallell utecklingsgren. 

### Vad händer rent praktiskt när man gör en merge?
Då sätter man samman två grenar/branches. Till exempel när man gjort ändringar i dev och sedan mergea den till main.

### Vad är skillnaden mellan att pusha till GitHub och att publicera direkt på t.ex. Netlify?
När man pushar till GitHub skickar man sin kod och sina commits från datorn till GitHub. Medan när man publicerar på Netlify gör man sin webbplats tillgänglig på internet så att du kan besöka den via en webbadress

### Om du vill exkludera någon fil i projektet från versionshanteringen, hur gör du då?
Du skapar en fil som kallas för .gitignore, lägga sedan i filnamnen i den. Då kommer Git att ignorera den automatiskt och inte synkas mot GitHub.
